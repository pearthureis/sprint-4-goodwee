# ChargeGrid — GoodWe EV Challenge

## Sobre o projeto

O ChargeGrid é um projeto desenvolvido para facilitar o carregamento de veículos elétricos, oferecendo praticidade para os usuários e controle para os operadores.

## Funcionalidades

### Aplicativo do usuário
- Iniciar o carregamento do veículo.
- Realizar pagamentos.
- Acompanhar o nível da bateria e a potência de carregamento.
- Tirar dúvidas com um assistente de inteligência artificial.

### Painel do operador
- Acompanhar os veículos em carregamento.
- Definir limites de potência para distribuir a energia entre os veículos.
- Receber solicitações de usuários que desejam falar com um atendente.

### Inteligência Artificial
O assistente está disponível tanto no aplicativo quanto no painel do operador. Ele responde às perguntas dos usuários e permite encaminhar solicitações para atendimento humano.

## Sustentabilidade

O projeto busca melhorar o aproveitamento da energia disponível durante o carregamento dos veículos elétricos, contribuindo para uma operação mais organizada e eficiente.

## Conclusão

O ChargeGrid reúne praticidade, inteligência artificial e gerenciamento de energia para tornar o carregamento de veículos elétricos mais simples e eficiente.
